# Primate Warfare Prototype

Low-poly Three.js MVP for five primate species:

- Baboon
- Bonobo
- Chimp
- Orangutan
- Sagui

The prototype uses procedural geometry instead of external model files so the current version stays easy to tune and fast to load. Each species has a distinctive silhouette, shared low-poly tactical armor, a simple AK-like rifle, T-pose rig check, relaxed carry, aim-down-sight pose, and basic idle / patrol / sprint / aim animations.

## Run

```bash
bun install
bun run dev
```

Then open `http://localhost:3022`.

## Build

```bash
bun run build
```
