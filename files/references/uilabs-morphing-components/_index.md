[uilabs](https://www.uilabs.dev/) is a showcase of polished morphing UI components. It is not open-source, but it is a strong inspiration reference.

Useful patterns:

- Two-step popover with animated transition between states.
- Action toolbar that changes shape/state to expose status and actions.
- Dynamic settings with smooth transitions and blur.
- Contextual toolbar that suggests actions based on where the user is.
- Feedback component that avoids a modal by transforming in place.
- Elastic card interactions for actions inside a card.
- Animated cards and dynamic header/footer widgets that reuse the same component shell for different meanings.

The common idea is stateful components that morph instead of spawning extra UI.
