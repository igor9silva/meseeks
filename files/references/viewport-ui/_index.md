[Viewport UI](https://viewport-ui.design/) is a curated catalog of UI/UX inspiration.

It is useful as a browsing surface for interaction patterns, motion, layout ideas, and visual polish across Web, Desktop, Mobile, Watch, iOS, Android, Icon, and Motion categories.

Examples visible on the homepage:

- Glassmorphic Notification Drawer
- Energy Score Interface
- Tasks and Calendar UI
- Financial App Screens
- Ongoing Task Interface
- Partnership Section on Website
- Chat Reaction Interaction
- Submit ID for Check In
- Website Template
