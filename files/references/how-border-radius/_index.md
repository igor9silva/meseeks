[How border radius works](https://howbr.vercel.app/) is an interactive visual reference for getting nested rounded corners right.

The useful rule is visible in the demo: when a container has padding, the child radius should account for that spacing instead of blindly repeating the same radius. The page shows outer radius, padding, inner radius, and generated CSS side by side.
