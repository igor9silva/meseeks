MarkItDown turns documents and media into Markdown for AI pipelines.

- [Repository](https://github.com/microsoft/markitdown)
- PDF, Word, Excel, PowerPoint, audio, and images to Markdown
- OCR, EXIF extraction, and transcription
- CLI, Python, and Docker interfaces
- Optional LLM-generated image alt text
- Batch folder processing

Source phrasing: "LLMs don't eat files. They eat structure."
