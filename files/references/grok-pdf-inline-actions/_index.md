UX reference for contextual actions inside a document/PDF reader.

The pattern is direct selection-to-action: highlight text, then offer precise actions like Explain or Quote right beside the selected content. This is a strong fit for task bodies, references, source docs, and generated reports where users should be able to ask about a specific passage without leaving the surface.
