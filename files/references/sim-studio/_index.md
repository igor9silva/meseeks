# Sim Studio

## Reference

Sim Studio / Sim is an open-source agent workflow builder. The useful reference for Meseeks is the product shape: a visual canvas for connecting agents, tools, integrations, model calls, document/RAG flows, and workflow blocks, with a natural-language copilot that can generate or edit flows.

Meseeks relevance:

- visual workflow canvas for agents/actions
- self-hostable/open-source posture
- agent workflow blocks plus integrations
- copilot-assisted workflow construction
- local model/self-hosting support as positioning reference

Sources:

- https://www.simstudio.ai
- https://github.com/simstudioai/sim
