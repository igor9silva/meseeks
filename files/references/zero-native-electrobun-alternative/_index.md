zero-native is an Electrobun alternative with native Layered WebViews.

Layered WebViews

For website builders, browsers, others with preview surfaces in zero-native

→ Render previews in real WebViews, not iframes
→ No iframe cookie/auth/storage pain
→ Isolated by default
→ Bridge access only when trusted

Web UI, stacked natively.
