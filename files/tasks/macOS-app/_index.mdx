Building on the ideas we learned with browser-poc/, but now on top of Electrobun!

- Build a native macOS browser-like app.
- Act as both browser and launcher.
- Visit normal websites and directly run Meseeks components in the same app.
- Run private components directly or any page on the web.
- Run user-owned components using web APIs and build UI for existing apps that follows user preferences.
- Basic web principle: trust the origin!
- Support P2P and decentralized address forms such as `dat://`, `ipfs://`, and `.eth` domains; expose hooks so new protocols can be added in user space or extensions.
- Let users run an LLM on page content before rendering, e.g. remove cookie banners or rewrite hostile page UI.
- Feature: Auto-accept/reject cookie banners.
- ENS support.
- Act as a local model provider: instead of installing a background agent, users should be able to download the macOS app and use it as a provider for local/private execution.
	- [Gemma local browser agent](https://x.com/googlegemma/status/2048805789788413984?s=46) is a useful reference: local WebGPU model, browser history search, page reading/summarization, and tab management.
- Our native launcher should replace Raycast entirely.
	- Reference: [SuperCmd open-source Raycast alternative](../../references/supercmd-open-source-raycast/_index.md)
- Users should be able to configure the initial page like a browser start/home page.
