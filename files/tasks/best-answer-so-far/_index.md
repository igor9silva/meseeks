Show an in-flight "best answer so far" summary while a Seek/search/research loop is still working.

The main surface should not force the user to watch crawling, thinking, and raw work logs. Keep that deeper work available for inspection, but make the default experience a continuously improving answer draft.

Exact source quote:

> The ideal Deep[er] Search UI doesn't show me what it's crawling and thinking. It shows me the in-flight "Best answer so far" summary, and optionally I can dig into the homework. It doesn't have to be all-or-nothing.
