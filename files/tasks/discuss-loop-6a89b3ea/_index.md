where it questions all assumptions

This is similar to Cursor's plan mode, but without producing a formal plan. The model keeps asking questions until it is satisfied that the task is clear enough, then executes.

Given how Meseeks works, where the task itself is already the plan, this might be the regular Seek loop with an `ask` skill available. The difference is behavioral: it should challenge assumptions and clarify missing context before acting, but it should not force one extra "approve plan" click once it has enough information.
