# Upgrade app schemas to native Zod 4 and remove Zodex

The app now uses Zod 4 and native JSON Schema persistence. [PR #85](https://github.com/igor9silva/meseeks/pull/85) introduced dual-format reads and the data migration. Production and its Preview have been migrated; [PR #86](https://github.com/igor9silva/meseeks/pull/86) removes the temporary Zodex reader and migration code while retaining recovery copies.

## Objective
Keep one shared Zod 4 schema layer across the app and Convex, with versioned JSON Schema for persisted skill contracts and exact BigInt codecs at JSON boundaries.

## Subtasks
- [x] Replace app-owned Zod 3 imports and Convex adapters with Zod 4.
- [x] Remove Zodex and use native Zod JSON Schema conversion with BigInt codecs.
- [x] Publish dual-format reads before migrating existing skill schemas.
- [x] Audit and migrate production and the PR Preview, preserving original schemas.
- [x] Prepare PR #86 with shared skill-call contracts, strict current-format reads and permanent compatibility tests.
- [ ] Complete review and explicitly authorized merge/release of PR #86 after its Preview verification.
