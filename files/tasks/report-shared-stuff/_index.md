title: Report shared stuff
priority: low
tags: [security, multi-player, status:backlog, class:task]
---

Add a reporting feature for shared Meseeks surfaces.

Users should be able to report shared tasks, actions, public outputs, comments, or other shared material when it is unsafe, abusive, misleading, or otherwise problematic.

Keep the first version simple:

- report button on shared surfaces
- reason/details field
- snapshot of the reported shared context
- reporter and target metadata
- internal review queue or admin notification

The important part is that shared multi-player content has an abuse/safety feedback path before it becomes a larger distribution surface.
