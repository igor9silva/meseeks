# Deprecate/deactivate mechanics for intelligences

We need a deprecation/deactivating system for AI models.

We basically want a timestamp that, after that, the model does not appear on IntelligenceSelector anymore, and the engine refuses to use it. The composer should also handle it nicely.

Actually, we need both deprecation and deactivation.

Deprecation renders a Deprecation notice as a Composer strip.
Deactivation turns it off entirely.

We must keep the ids because of history and type safety.
