## Objective

First, remove deferred-work markers from code by converting every still-useful marker into a tracked disk task or folding it into an existing tracked disk task.

After that extraction pass, resolve the highest-risk tracked tasks with implementation and tests. The codebase should not use `TODO`, `FIXME`, `HACK`, `XXX`, or `BUG` comments as the source of truth for deferred work.
