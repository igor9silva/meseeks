Build a Meseeks theme builder inspired by [tweakcn](https://tweakcn.com/editor/theme?tab=typography).

Also shadcn's own builder: https://ui.shadcn.com/create

The useful reference is a live shadcn/ui theme editor that previews colors, typography, radius, and style changes in real time. We want the same kind of fast feedback loop for Meseeks themes, tuned to our shared UI package and product surfaces.
