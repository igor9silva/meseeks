Add support for more libraries in Compositions, our rendering system for AI-generated code.

Start with the libraries Lovable showcased as useful app-generation targets, plus the original Meseeks note about `tscircuit`:

- [Three.js](https://threejs.org/) for 3D scenes and interactive graphics.
- [Fabric.js](https://fabricjs.com/) for interactive canvases.
- [p5.js](https://p5js.org/) for creative visuals.
- [D3](https://d3js.org/) for custom data visualizations.
- [Highcharts](https://www.highcharts.com/) for production charting.
- [React Flow / xyflow](https://reactflow.dev/) for node-based UIs.
- [tscircuit](https://tscircuit.com/) for electronics/circuit design with TypeScript, React, and AI tools.
