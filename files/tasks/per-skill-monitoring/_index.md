Build a backoffice view to inspect, monitor, and improve skills.

It should make skill behavior visible enough to debug failures, compare outcomes, spot weak prompts/tools, and decide what needs tuning.

The view should let us inspect recent executions per skill, including input, output, what the skill did, and the final result. From there we should be able to judge runs, leave direct feedback, and trigger learning/improvement from that evidence.
