Composable prompts powered by MDX and React.

Useful ideas: React/MDX components as prompt fragments, prompt rendering as a testable string-generation target, reusable prompt sections, and structured XML-like prompt tags.

Relevant to Meseeks bi-rendering as a reference for component-defined AI output. Not necessarily the runtime choice.
