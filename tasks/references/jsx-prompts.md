JSX-to-Markdown prompt construction reference.

Useful distinction: Priompt focuses on message ordering, priorities, and context-window management; jsx-prompts focuses on rendering structured data into the body of a message as Markdown.

Relevant to Meseeks bi-rendering because one component tree can target AI-readable Markdown instead of DOM.
