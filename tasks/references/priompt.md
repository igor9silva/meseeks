Anysphere's JSX prompt design library.

Useful ideas: prompt trees as components, priorities and fallbacks, token budgeting, message components, source maps, and explicit token reservations.

Warning worth preserving: priority-heavy prompt design can hurt prompt-cache stability and become its own complexity.
