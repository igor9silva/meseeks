title: Add user device information to context
priority: low
tags: [source:ticktick, ticktick-list:meseeks, ticktick-status:inbox, status:backlog]

Add lightweight user device information to Meseeks context so tasks can account for the current environment.

Useful context can include device type, OS/browser/app shell, timezone/locale when relevant, viewport constraints, and input constraints.

Keep it limited to context that can change behavior. Do not turn it into creepy fingerprinting data.
