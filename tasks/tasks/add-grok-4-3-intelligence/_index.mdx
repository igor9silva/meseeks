# Add Grok 4.3 intelligence

Grok 4.3 is a candidate xAI model for the Meseeks intelligence registry. The current blocker is that Grok 4.3 cannot turn reasoning off, so Meseeks needs first-class reasoning support before this model is enabled.

## Objective
Add support for `xai/grok-4.3` after reasoning behavior is represented explicitly and verified. Acceptance criteria: `xai/grok-4.3` is present in the intelligence key schema, metadata registry, and runtime model map; the model uses the correct xAI provider options for reasoning; at least one tool-required action run completes successfully; `bun typecheck` passes.
