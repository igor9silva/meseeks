# Public

Public work is the part of Meseeks that can live in the main repo.

Everything here should be useful without private context. If a task mixes public product work with personal or sensitive detail, split it and keep the private part under the private root.

Use this root for product work, public engineering tasks, technical references, public ideas, and imported work that has been reviewed for visibility.
