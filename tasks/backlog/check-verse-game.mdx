We are prototyping CheckVerse: a fast strategy game with chess DNA, not just “chess with funny pieces”.

The original pitch was a smaller, faster chess variant: same pawn row, variable backline pieces, power-ups, and enough randomness that every game is not identical. The corrected pace target is blitz chess energy: about `3+2`, not a 10-minute match.

The theme should be open crossover arena, closer to Fortnite than medieval fantasy or obvious war. Any character can exist in the game: rapper, anime hero, robot, wizard, athlete, meme skin. The gameplay stays readable because rules are attached to roles, not skins.

Classical chess role names should remain classical. If a character moves like a Knight, the UI says `Knight`. Do not rename classical roles into cute equivalents like “VIP”, “Grunt”, or “kit”. Use `Role` for the player-facing rules layer and “movement pattern” when explaining how the role moves.

## Current Prototype

There is already an `apps/check-verse/` MVP using Vite, TypeScript, and Three.js.

Current implemented direction:

- `6x6` board
- same pawn row concept
- variable/custom backline pieces
- custom roles such as `Lancer`, `Archer`, `Warden`, `Cannon`, `Mystic`, and `Duelist`
- power-ups such as `Tempo`, `Surge`, `Dash`, and `Forge`
- top-down horizontal camera with White at the bottom
- selected-piece highlight, legal-move target guides, and move-shape diagrams
- default blitz pacing of `3+2`

Last known verification:

- `bun run typecheck`
- `bun run build`
- browser visual checks at desktop and mobile sizes

## Product Vision

Build a fast, readable, collectible strategy arena:

- Rules are chess-readable.
- Characters are visually wild.
- Roles define gameplay.
- Skins define personality, animations, and effects only.
- Cosmetics never change movement, capture rules, timers, odds, or power.

Example player-facing labels:

- `Snoop Dogg · Knight`
- `Goku · Queen`
- `Robot Samurai · Rook`
- `Tiny Wizard · Bishop`
- `Cursed Mascot · Cannon`

Future modes can split cleanly:

- Classic mode: exact chess roles and rules, skins only.
- Arena mode: smaller board, draft/custom roles, power-ups, fast clocks.

Do not prioritize modes yet. The immediate goal is making the core vision feel coherent.

## Naming Notes

`CheckVerse` is the current working name. It has a namespace collision with `checkverse.com`, but we are accepting that risk for now because it fits the chess-readable crossover arena direction better than the cleaner alternatives.

Rejected or weak:

- `MateMe`: awkward meaning and bad “mate me” connotation.
- `MateMate`: occupied/noisy.
- `SupaMate`: occupied/noisy.
- `Checkout`: impossible because of the payment/ecommerce namespace.
- `BoardRoyale`: already used by a survival card/board game.
- `Turnfight`: already used by a browser air-combat game.
- `Moveverse`: already used by motion/browser games.
- `Rolemate`: already used by AI companion/job-search apps and has the wrong vibe.

Previous ranked shortlist from the 2026-05-01 namespace pass:

1. `Checkstars` — best fit for crossover characters, celebrity skins, and chess-readable “check”; `.com` has DNS and there are unrelated uses, but it is not strongly owned by a game.
2. `MateBolt` — cleanest namespace and fast-game energy; less expressive of the crossover/lore angle.
3. `Crownverse` — clean DNS across common TLDs and crown/chess-adjacent; weaker and more generic as a game name.
4. `CheckRush` — understandable speed/chess name, but `.com` is a premium domain for sale and it feels more utility than arena.
5. `Boardstars` — decent crossover vibe, but weaker chess signal and occupied by unrelated brands.
6. `Movefight` — mostly available, but it sounds clunky and has unrelated fitness/company noise.
7. `CheckVerse` — good meaning but occupied by `checkverse.com` and previously ranked lower for namespace cleanliness.
8. `BoardRoyale` — avoid; already a game.
9. `Turnfight` — avoid; already a game.
10. `Moveverse` — avoid; already a motion-games product.
11. `Rolemate` — avoid; wrong category associations.
12. `Checkout` — avoid; payment namespace dominates.

Working decision: use `CheckVerse` for now.

## Acceptance Criteria

- The prototype no longer feels like “generic chess clone with renamed pieces”.
- A new player can tell what every piece does from role labels and visual move diagrams.
- A skinned character never hides or changes its role.
- The pace supports roughly `3+2` games.
- The code keeps gameplay rules separate from presentation/skins.
- Naming decision and rationale are captured in the task before broader polish.
